# AGENTS.md

## Cursor Cloud specific instructions

Cleo is a Next.js 16 + Convex app. Standard commands live in `README.md` and `package.json` scripts; this section only captures non-obvious startup/run caveats.

### Services (both must run for end-to-end use)
- Convex backend (local anonymous): `npm run convex:dev` — long-running, serves DB/auth/AI HTTP actions at `http://127.0.0.1:3210`. Keep it running in its own terminal.
- Next.js frontend: `npm run dev` — serves the UI at `http://localhost:3000`.

### One-time backend setup (only needed when the Convex backend has no data yet)
The anonymous Convex backend stores its state (schema, tables, and env vars set via `npx convex env set`) locally, separate from the repo. If it is fresh/empty, do this **in order**:
1. Start `npm run convex:dev` first and wait for `Convex functions ready!` (or run `npm run convex:push` once). The backend must be listening on `127.0.0.1:3210` before the next steps.
2. `npm run setup:auth` — generates and sets `JWT_PRIVATE_KEY` + `JWKS`. This FAILS with "Local backend isn't running" if the backend is not up yet, so never run it before step 1.
3. `CONVEX_AGENT_MODE=anonymous npx convex env set SITE_URL http://localhost:3000` — required for auth redirects.

`npx convex env set ...` also requires the backend to be running. `.env.local` (with `NEXT_PUBLIC_CONVEX_URL`) is auto-generated by the Convex CLI; do not hand-edit or commit it (gitignored).

### Gotchas
- `npm run convex:push` uses `--once`: it deploys and then exits (shutting the backend down). Use the long-running `npm run convex:dev` when you need the backend up for `setup:auth` / `env set` / running the app.
- Email/password sign-up works on the local anonymous backend (despite the caveat in `known-issues.md`); a new account redirects to the home/document list.
- AI assistant, Google OAuth are optional and need keys set via `npx convex env set` (`OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `GEMINI_API_KEY`, `AUTH_GOOGLE_ID` / `AUTH_GOOGLE_SECRET`). The editor works without them.
- Lint (`npm run lint`) currently reports pre-existing errors in the repo; a clean run is not expected.
